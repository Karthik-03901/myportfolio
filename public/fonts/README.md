# Fonts Directory

## Required Fonts

Download these fonts and place them in this directory:

### Clash Display (Fontshare)
- Download from: https://www.fontshare.com/fonts/clash-display
- Files needed:
  - `ClashDisplay-Semibold.woff2` (weight 600)
  - `ClashDisplay-Bold.woff2` (weight 700)

### General Sans (Fontshare)
- Download from: https://www.fontshare.com/fonts/general-sans
- Files needed:
  - `GeneralSans-Regular.woff2` (weight 400)
  - `GeneralSans-Medium.woff2` (weight 500)

## Note
Google Fonts (Instrument Serif Italic and JetBrains Mono) are loaded automatically via next/font/google.
